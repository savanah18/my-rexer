# Research Skills Repository

This directory contains specialized skills for the AI research agent.

## Skill Categories

### Web Research Skills
- Web scraping and extraction
- Source validation and credibility assessment
- Content synthesis and summarization

### Knowledge Management Skills
- Knowledge graph construction
- Semantic indexing and retrieval
- Cross-source correlation

### Autonomous Reasoning Skills
- Hypothesis generation
- Research path planning
- Evidence evaluation

## Usage

Skills are loaded at runtime and dynamically invoked based on research context.
