# Knowledge Synthesis Skill

## Description
A skill for synthesizing and organizing research knowledge from multiple sources.

## Capabilities
- Knowledge extraction and structuring
- Cross-source pattern matching
- Semantic relationship mapping
- Knowledge graph construction

## Usage
```javascript
const knowledge = await researcher.synthesize({
  sources: [...],
  context: "current research state",
  focus: ["deep learning", "neural architectures"]
});
```
