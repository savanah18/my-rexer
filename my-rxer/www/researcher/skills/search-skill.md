# Research Search Skill

## Description
A skill for conducting autonomous searches across web and knowledge sources.

## Capabilities
- Multi-source search orchestration
- Query refinement and expansion
- Source verification and ranking
- Result synthesis and summarization

## Usage
```javascript
const searchResult = await researcher.search({
  query: "AI research topics",
  sources: ["web", "academia", "preprints"],
  iterations: 3
});
```
